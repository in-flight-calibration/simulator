# Simulator

## Features
* Links ROS2 with FlightGear

## Installation
### Install ROS2 (https://www.ros.org/)

### Install FlightGear (https://www.flightgear.org)

Ubuntu:

    sudo add-apt-repository ppa:saiarcot895/flightgear
    sudo apt-get update
    sudo apt-get install flightgear flightgear-data

Fedora:

    sudo dnf install FlightGear FlightGear-data
